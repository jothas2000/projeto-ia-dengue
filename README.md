# Projeto 1 — Agente de Combate à Dengue

Disciplina: **Inteligência Artificial** — Curso de Bacharelado em Ciência da Computação (BCC)
Universidade Tecnológica Federal do Paraná (UTFPR) — Campus Ponta Grossa

## Descrição

Simulação computacional em que um **usuário** (controle manual) e um **agente inteligente**
(controlado por algoritmo de busca) tentam alcançar o mesmo foco de proliferação do mosquito
*Aedes Aegypti* a partir da mesma posição inicial, em um ambiente representado por uma matriz
(grid) com diferentes tipos de terreno, custos de deslocamento e obstáculos.

O objetivo é comparar, para o mesmo cenário, o desempenho de diferentes estratégias de busca
entre si e contra a decisão humana.

## Algoritmos implementados

- Busca em Largura (BFS)
- Busca em Profundidade (DFS)
- Busca Gulosa
- A* (com heurística baseada em Distância Manhattan)

> Implementação própria dos algoritmos de busca (sem uso de bibliotecas prontas), conforme
> exigido pelo enunciado do projeto.
